# Астролог

Настольное Java-приложение для определения знака зодиака по дате рождения и вывода краткой астрологической информации.

| | |
|---|---|
| **Дисциплина** | Жизненный цикл разработки программного обеспечения |
| **Автор** | Зелень Александр Иванович |
| **Язык** | Java |
| **GUI** | Swing |
| **Архитектура** | MVC с активной моделью |

## Назначение

Пользователь вводит дату рождения. Приложение проверяет корректность даты, определяет соответствующий знак зодиака западного гороскопа и показывает его название, стихию, управителя и описание.

## Возможности

- ввод дня, месяца и года рождения в отдельном диалоге;
- проверка, что дата существует в григорианском календаре;
- ограничение года: от 1900 до текущего;
- определение одного из 12 знаков зодиака;
- отображение даты, названия знака и астрологической справки;
- сообщения об ошибках при некорректном вводе.

## Архитектура

Приложение построено по шаблону **MVC с активной моделью**: модель хранит данные и сама уведомляет представление об изменениях.

```
Main
 ├── ZodiacModel          (Model)     — дата, знак, подписчики
 ├── AstrologController   (Controller) — ввод, валидация, запись в модель
 └── MainView             (View)      — главное окно, подписчик модели
         └── InputDialog              — диалог ввода даты
```

| Класс | Роль |
|-------|------|
| `Main` | Точка входа: создаёт модель, контроллер и представление |
| `ZodiacModel` | Хранит дату и результат, валидирует данные, оповещает слушателей |
| `AstrologController` | Открывает диалог ввода и передаёт данные в модель |
| `MainView` | Главное окно; реализует `ModelListener` и обновляется по событию модели |
| `InputDialog` | Модальное окно для ввода дня, месяца и года |
| `ZodiacSign` | Перечисление знаков зодиака с диапазонами дат и описаниями |

После успешного `setData(...)` модель вызывает `notifyListeners()`, и `MainView.onModelChanged()` обновляет интерфейс без прямого участия контроллера.

Диаграмма классов: [`docs/uml/mvc-active-model.puml`](docs/uml/mvc-active-model.puml).  
Компонентная схема SysML: [`docs/sysml/AstrologApplication.sysml`](docs/sysml/AstrologApplication.sysml).

## Требования

- JDK 17 или новее (в проекте IntelliJ указан JDK 25);
- IntelliJ IDEA или другой способ скомпилировать и запустить Java-приложение;
- стандартная библиотека Java SE (`javax.swing`, `java.time`) — внешних зависимостей нет.

## Запуск

### IntelliJ IDEA

1. Откройте каталог проекта.
2. Убедитесь, что назначен JDK.
3. Запустите конфигурацию **Main** (`astrologia.Main`).

### Командная строка

```bash
javac -d out src/astrologia/*.java
java -cp out astrologia.Main
```

На Windows в PowerShell:

```powershell
javac -d out src/astrologia/*.java
java -cp out astrologia.Main
```

## Пример работы

1. Нажмите **«Узнать свой знак Зодиака»**.
2. Введите день, месяц и год (например, `21`, `3`, `2000`).
3. Нажмите **OK**.
4. В главном окне отобразятся дата, знак (Овен) и описание.

Некорректные значения (буквы вместо чисел, 31 февраля, год вне диапазона) отклоняются с сообщением об ошибке.
